# Documentary acceptance subject

`archival_researcher_cutout.png` is an original AI-generated fictional
archival researcher created for the ChrononMotion3D documentary acceptance
scene. It does not depict or imitate a named person. The PNG is RGBA with a
transparent background; its SHA-256 is recorded in
`../documentary_fonts/manifest.v1.json`.

The final test uses this subject in a full layered documentary sequence. It
does not use the old MrBeast cutout or the old T16 render output.
